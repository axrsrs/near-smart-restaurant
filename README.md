# NEAR Smart Restaurant

Self servis ve gel-al işletmeleri için sipariş takip sistemi.

## Geliştirme

```bash
npm install
npm run dev
```

## Tema

Renkler `src/index.css` içindeki `@theme` bloğunda tanımlıdır (Tailwind v4).
Vurgu rengi tarihsel nedenle `gold` adını taşır; değeri mavidir (#1d5fa8).
